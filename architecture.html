Build Script
Python 3
🐍
generate_skins.py
Run manually after each LoL patch to refresh data
Fetches all 3 sources sequentially using urllib (no dependencies)
Merges data by skin ID — resolves tier, RP, availability, lore, skin line
Tier refinement: kNoRarity + RP ≤ 520 → Budget tier
Availability logic: isLegacy → Legacy · kRare → Rare · Prestige → Limited
Outputs skins-data.js with window.SKINS = [...] global array
writes → overwrites
