How It Was Built
01
I
🗃️
Phase One

Concept & Data Pipeline

  • Goal: build a browsable, filterable database of every League of Legends skin ever released — something the official client doesn't offer
  • Identified three data sources to merge: Data Dragon (official Riot API), Community Dragon (extended metadata), and Meraki Analytics (skin lines & tier data)
  • Wrote generate_skins.py to automate the entire pipeline — fetches, merges, cleans, and outputs a single skins-data.js file
  • Result: 896 skins bundled as a static JS file — the site never needs to call an API at runtime
Python Data Dragon API Community Dragon Meraki Analytics 896 skins
02
II
🎨
Phase Two

Design & Build

  • Dark theme using official Riot fonts — Beaufort for LoL (headings) and Spiegel (body), the exact same typefaces used inside the game client
  • Full-bleed card grid with tier-matched hover glows — Legendary cards glow gold, Epic cards glow purple, matching the in-game rarity system
  • Built entirely as a static site — HTML, CSS, and vanilla JS only. No frameworks, no build tools, no backend. Deployable to GitHub Pages instantly
Beaufort for LoL Spiegel HTML / CSS / JS Zero Backend GitHub Pages
03
III
⚔️
Phase Three

Features Shipped

  • Multi-filter system — filter by tier, champion, skin line, release year, and availability — all combinable
  • Live search across all 896 skins as you type, no delay
  • Sort options — newest first, oldest first, alphabetical, and by tier
  • Pagination with load-more to keep initial render fast
  • Skin detail modal — click any card to see full splash art and metadata
5 Filter Types Live Search 4 Sort Modes Detail Modal Pagination
04
IV
📊
Phase Four

Post-Launch & Analytics

  • Added a passion project disclaimer to the footer — clearly not affiliated with Riot Games
  • Updated the architecture diagram to accurately document the GitHub + GitHub Pages hosting model for the team
  • Integrated Google Analytics 4 with custom event tracking across 10 user actions: skin views, searches, all filter types (tier, champion, skin line, year, availability), sort changes, load more, and filter resets
  • Full visibility into which champions are searched most, which tiers are browsed, and how users navigate the vault
